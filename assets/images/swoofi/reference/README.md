The photos, Swoofi logo and six category icons are extracted from the user's
supplied `Swoofi — Meet Swoofi.png` design. Text, cards, header, scrolling and
category interactions are native Flutter widgets.

The hero's left margin is transparent to avoid duplicating text from the source.
The bundled Roboto fonts use the license in `assets/fonts/swoofi/roboto_license.txt`.
